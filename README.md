# PHOTO-MATIC

在瀏覽器裡用的美式拍貼機，首頁招牌寫著 SAY CHEESE!。選相紙、換背景、套濾鏡，倒數連拍後貼上像素貼紙，就能下載照片和會動的拍貼。

## 玩法
1. 選相紙：經典直條、四宮格、拍立得
2. 選背景、陰影、濾鏡，按下開始後會倒數連拍
3. 點照片可以單獨重拍
4. 選相框顏色、貼貼紙、決定要不要印日期
5. 沖洗，下載 PNG 和 MP4

## 上線
把 `index.html` 推到 GitHub，開 GitHub Pages 就能用。相機一定要在 https 下才打得開，用本機開檔案不行。

## 用到的外部資源
- 去背：MediaPipe 的 selfie segmenter，從 jsDelivr 和 Google Storage 載入
- 字型：Archivo Black、VT323、Noto Sans TC
