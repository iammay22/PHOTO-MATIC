# PHOTO-MATIC 企劃書

## 概念
在手機或電腦打開就能用的拍貼機，介面走美式復古風。拍完可以下載照片和會動的拍貼，給想拍拍貼、但不想專程跑一趟拍貼店的人用。

## 核心循環
選相紙 → 選背景、陰影、濾鏡 → 倒數連拍 → 不滿意的那張單獨重拍 → 選相框、貼貼紙、印日期 → 沖洗並下載 PNG 和 MP4 → 再拍一組。

## 畫面清單
- 首頁：招牌、三種相紙（經典直條 4 格、四宮格、拍立得 1 張）、投幣開始
- 拍照：即時預覽、背景／陰影／濾鏡三個分頁、照片格子（點了可以單張重拍）、倒數和閃光
- 裝飾：會動的成品預覽、相框顏色、日期開關、像素貼紙（拖曳、縮放、旋轉、刪除）
- 沖洗中：機台吐相紙的動畫和進度條
- 結果：動態和照片切換、下載 MP4、下載 PNG、分享、再拍一組

## 背景怎麼做才不假
- 背景照著真實拍貼店的布景畫：豹紋、酒紅布幕、橄欖綠牆、木紋牆、藍色畫布、灰背景紙。每款都有材質，再加上中間亮、四角暗的光線
- 人像後面加陰影，不用白邊。柔光影比較散，像攝影棚的感覺；閃光燈影往右下偏、邊緣比較清楚，像拍貼機的直閃。每款背景有預設的陰影，也可以自己換
- 濾鏡和顆粒套在合成好的整張照片上，人和背景就會在同一個色調裡
- 去背在瀏覽器裡跑，照片不會上傳

## 數值
- 照片格：直條 640×480、四宮格 480×640、拍立得 640×800
- 動態：快門前 1 秒錄到快門後 0.6 秒，約 20 格，播放時來回循環
- 影片輸出：照片尺寸的 0.6 倍，大約 6 秒

## 要收集的指標
`ENDPOINT` 填了才會送，目前留空。

- `start`：按下投幣開始，value 是相紙種類
- `shoot_done`：拍完整組，value 是「背景/濾鏡」
- `develop`：按下沖洗
- `download`：value 是 png、mp4 或 webm
- `share`：value 是 video 或 png
